# HP Newsletter

HP Newsletter is a web-based news platform designed to provide users with an organized and convenient way to explore news articles across different categories. The application brings together featured stories, category-based browsing and article discovery features in a single interface.

The platform focuses on making news browsing simple and accessible through an interactive interface with search, filtering and sorting capabilities.

**Live Application:** [HP Newsletter](https://hp-newsletter-delta.vercel.app/)

## Features

- **Top Stories:** Displays featured news articles to help users discover important stories.
- **Category-Based Navigation:** Browse articles across different categories, including Global, National, Sports, Business, Politics and Drama.
- **Search Functionality:** Find relevant news articles using keywords.
- **Date-Based Filtering:** Filter articles according to their publication date.
- **Sorting Options:** Organize articles by publication date, from newest to oldest or vice versa.
- **Article Details:** Access individual articles with information such as headline, author, publication date, reading time and article content.
- **Responsive User Interface:** Provides an organized browsing experience with responsive navigation and Bootstrap-based components.

## Technology Stack

**Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5

**Backend:** Node.js, Express.js

**Database:** Firebase Firestore

**Additional Tools:** Firebase Admin SDK, Git, GitHub and Vercel

## Application Overview

HP Newsletter follows a frontend-backend architecture. The frontend provides the user interface for browsing and interacting with news articles, while the backend handles application requests and communicates with Firebase Firestore for data management.

The application supports retrieving and presenting articles, organizing content by categories, and providing search, filtering and sorting functionality to improve the overall browsing experience.

## Getting Started

To explore the application, visit the deployed version:

[https://hp-newsletter-delta.vercel.app/](https://hp-newsletter-delta.vercel.app/)

For local development, the project requires Node.js, npm and Firebase configuration. Install the project dependencies using `npm install` and start the backend using `npm start` after configuring the required Firebase credentials.

## Project Objective

The objective of HP Newsletter is to develop a centralized platform for presenting news content in a structured and user-friendly manner. By combining category-based navigation, article discovery and content filtering, the application aims to make accessing and exploring news more convenient.
